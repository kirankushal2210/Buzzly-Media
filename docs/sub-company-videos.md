# Sub-company videos: descriptions and scripts (DRAFT for approval)

Three motion-graphics videos, one per sub-company, made entirely in code (no footage).
Each is rendered twice from the same animation: **1080×1920 vertical** for Instagram Reels,
and **1080×1080 square** for the website's Inside Buzzly panel.

**How to review:** correct anything that is wrong, fill in the ❓ questions, and delete what you
don't want. Nothing is rendered until you approve this document.

Source tags on every line of on-screen text:
- **[site]** already published on buzzly.in (from `lib/content.ts` or `lib/work.ts`)
- **[draft]** new wording written for the video; approve, edit or delete
- No numbers, clients, follower counts, reviews or locations are invented. Where a real fact
  would make a scene stronger, there is a ❓ question instead.

---

## Shared look (all three videos)

| | |
|---|---|
| Length | ~20 seconds each (the sweet spot for a reel that is watched to the end) |
| Base colours | Buzzly dark `#151313`, cream `#f5efdf`, Buzzly red `#ef342d` |
| Accent per company | De Food Kampney `#d69454` (warm amber) · Buzzly Health `#b5c9b1` (sage) · Buzzly Properties `#b7c8c8` (stone blue) |
| Type | Instrument Serif for headlines (italic for the accent word), DM Sans for small labels: the same as the website |
| Motion | Calm and premium: smooth slow-out entrances, faster exits, no bounces, shakes, neon or glitch. One moving element at a time. |
| Instagram shots | Drawn in code inside a phone frame: a reel playing, a profile grid filling up, a story with a poll, a post caption typing out. **No fake likes, follower counts or customer comments.** Any counter is left blank or shown as an icon only. |
| Ending | Company name + "A Buzzly sub-company" + `buzzly.in` |
| Sound | Rendered silent; music is picked in Instagram when posting (licence-safe). Optional soft UI sounds on taps. |
