Illyism/seo-skills guide (adapted; the skills themselves are not installed).

| File | What it holds |
|---|---|
| `context.md` | Facts about Buzzly that pages may state, each with its source on the site |
| `keyword-map.csv` | One target search phrase per page. **Proposed, not validated**: no search data yet |
| `ai-prompts.md` | 10 buyer questions to ask AI tools; log answers in the CRM (GTM → AI visibility) |
| `backlog.md` | SEO to-do list, in priority order |
| `log.md` | What changed and when |

Rule: never publish a number, client, quote or claim that isn't in `context.md` with a source.
